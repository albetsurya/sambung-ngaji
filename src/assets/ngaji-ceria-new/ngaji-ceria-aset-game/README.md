# Ngaji Ceria - Aset Pengganti Emoji untuk Mini-Game

Gaya: claymorphism / soft 3D vector. Gradasi pastel, outline tipis 1.5px, bayangan tebal di sisi bawah, sudut membulat.
Palet utama: Hijau Tilawati #2D5A27, Oranye Ceria #F58A3A, Emas #FFCB45, krem #FFF8EE.

## Pemetaan emoji ke aset
Sholat Hero (prayers.ts): subuh=iconSholatSubuh, dzuhur=iconSholatDzuhur, ashar=iconSholatAshar, maghrib=iconSholatMaghrib, isya=iconSholatIsya
Adab RPG (AdventureMap.tsx): gerbang=mapGerbang, masjid=buildingMasjid, kelas=buildingKelas, asrama=buildingAsrama, perpus=buildingPerpus,
  lapangan=mapLapangan, ruang tamu=mapRuangTamu, taman=mapTaman, malam=mapMalam
Santri Idle (buildings.ts): rumah=buildingRumah, sekolah=buildingKelas, masjid=buildingMasjid, dapur=buildingDapur, perpustakaan=buildingPerpus
Wudhu Flow (steps.ts): stepNiat, stepCuciTangan, stepBerkumur, stepHirupAir, stepBasuhWajah, stepBasuhTangan, stepUsapKepala, stepUsapTelinga, stepBasuhKaki, stepDoaSelesai
Ayat Hunter (HunterArena.tsx): obstaclePohon
Hijaiyah Rush (RunnerField.tsx): obstacleBatuRintangan, obstaclePagar, obstacleSemak, obstacleBalokKayu
Tajwid Arena (Card.tsx): cardBackgroundTajwid (emas), cardBackgroundTajwidPerak; efek jawaban benar: effectSparkleCorrect

Aset tanpa teks, jadi tidak membutuhkan font tambahan. buildingDapur dan effectSparkleCorrect memiliki animasi SMIL ringan.

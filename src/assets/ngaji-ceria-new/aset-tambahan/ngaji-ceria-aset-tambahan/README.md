# Ngaji Ceria - Aset Tambahan

Gaya sama dengan paket 200 aset Tilawati (rim gelap 3D, cincin putih, gradasi lembut, sudut membulat).

- 01-cover-game: coverTangkapHarakat, coverSusunKata, coverDetektifSuara, coverRodaHijaiyah (rasio 4:3, viewBox 400x300)
- 02-badge-hasil: badgeBintang3 / 2 / 1 (viewBox 360x200; bintang kosong berwarna abu)
- 03-efek: efekPopBalon (letusan balon, animasi singkat sekali jalan; ganti ke tampilan statis dengan menghapus tag animate)
- 04-peti-dan-ikon: petiBonusEmas (animasi: sinar berputar, koin memantul, kilau berkedip), iconTimerPasir (jam pasir dengan tanda plus)

Catatan: huruf Arab memakai font Amiri / Noto Naskh Arabic. Muat font tersebut di aplikasi atau konversi teks ke path.
Paket ini berdiri sendiri dan tidak menimpa nama file pada paket 200 aset.
